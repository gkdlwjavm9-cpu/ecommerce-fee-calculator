# Ecommerce Fee Hub

Fee, net-payout and break-even-ROAS pages for 19 ecommerce platforms at 12 price points (282 pages),
generated by a Python static generator and deployed on GitHub Pages.

- Hub: https://gkdlwjavm9-cpu.github.io/ecommerce-fee-calculator/
- Calculator: https://gkdlwjavm9-cpu.github.io/ecommerce-fee-calculator/calculator/
- Rates read from each platform's own fee page on 11 November 2026 (US, US seller, domestic buyer).

Structure: `/fees/{platform}/{price}/`, `/compare/{a}-vs-{b}/`, `/best/{category}/`, `/guides/`, `/methodology/`.
Every page carries JSON-LD (WebPage + BreadcrumbList + FAQPage), is internally linked, and lists its platform source.

The paid companion workbook is the Multi-Channel Unit Economics & Fee Audit Kit on Gumroad.
